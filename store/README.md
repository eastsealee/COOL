# 쭈갑과물때 — 플레이스토어 버전

개인 버전(`personal/`)과 달리 **상업적으로 써도 되는 자료만** 쓰고, 화면을 앱 안에 넣어 Streamlit 없이 바로 열리게 만드는 앱.

## 넣을 기능
| 기능 | 자료 출처 (공공누리 등 상업 이용 가능) | 개인 버전과 다른 점 |
|---|---|---|
| 물때 시계 | 해양조사원 조석예보(고·저조)·TideBED | 바다타임 대신 해양조사원 |
| 날씨·바람 | 기상청 단기예보(3일)·중기 해상예보(4~10일) | Open-Meteo 대신 기상청 |
| 수온 | 해양조사원 조위관측소 실측 + 보정 | 같은 자료 |
| 조류 레이더 | 해양조사원 조류예보 + 휴대폰 GPS | 같은 자료 |
| 채비 계산기 | 앱 안 계산 (물리 모델) | 같음 |
| 입질 확률 | 앱 자체 점수 모델 | 라마르호 기록 보정은 뺌 |

빼는 것: 선상낚시 예약조회, 라마르호 예상분석 (남의 자료)

## 폴더
```
store/
├─ web/      앱 안에 들어가는 화면 (HTML·JS) — 물때 시계, 조류 레이더, 채비 계산기, 입질 확률
├─ data/     자료 만드는 스크립트 (GitHub Actions가 실행 → JSON 파일로 올림, 인증키는 서버에만)
└─ app/      안드로이드 앱 (Kotlin) — web/ 화면을 앱 안에 넣어 실행, 새 패키지 이름·서명키
```

## 플레이스토어 준비물 (차례대로)
1. 자료: 해양조사원 조석예보·기상청 예보를 Actions로 받아 JSON으로 올리기 (`store/data`)
2. 화면: 개인 버전 화면을 공공 자료용으로 옮기기 (`store/web`)
3. 앱: 새 패키지 이름(예: `kr.jjugap.mulddae`), 업로드용 서명키, AAB 빌드 (`store/app`)
4. 스토어: 개발자 계정(1회 $25), 개인정보처리방침 주소, 데이터 보안(위치 사용) 설명, 스크린샷
5. 확인: 기상청 콜센터(131)에 기상예보업 등록 필요 여부, 지도는 상업 이용 가능한 곳으로
